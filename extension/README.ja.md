# Jev Ultrafast 拡張機能（Chrome / Edge）

好きなサイトの上に、Jev のパネルを出すための小さな拡張機能です。
パソコンの Chrome か Edge で使えます。

## 入れかた（1回だけ）

1. この `extension` フォルダを、パソコンに置きます。
   （zip の場合は、右クリックして「すべて展開」します）
2. Chrome を開き、アドレス欄に `chrome://extensions` と入れて Enter。
   Edge は `edge://extensions` です。
3. 右上の「デベロッパー モード」を ON にします。
4. 「パッケージ化されていない拡張機能を読み込む」を押します。
5. `extension` フォルダ（`manifest.json` が入っているフォルダ）を選びます。
6. ツールバーのパズルのマーク → 「Jev Ultrafast パネル」のピンを押すと、いつでも押せます。

## 使いかた

1. 操作したいサイト（例: https://suumo.jp/sp/）を開きます。
2. ツールバーの Jev のボタンを1回押します。右側にパネルが出ます。
3. 「Jev にやって欲しいこと」を書いて「スタート」。
4. もう一度ボタンを押すと、パネルが消えます。

## 安全について

- 使う権限は「今のタブ」だけです（activeTab / scripting）。
- 外から読み込むプログラムはありません。
- 通信するのは、「Jev モード」にあなた自身のキーを入れて使ったときだけです（入れなければ何も送りません）。キーはパネルを閉じると消え、サイトには保存されません。
- 購入・注文・送信・ログインなどのボタンは押しません。

## 困ったとき

- ボタンに「×」が出たら、そのページでは使えません（chrome:// のページなど）。
- 拡張機能を更新したら、`chrome://extensions` で「更新」の丸い矢印を押します。
